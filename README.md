# MatriTrack Mobile (Expo)

Cross-platform starter app (iOS + Android) matching your provided home-screen concept, configured for Expo SDK 54.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npm run start
   ```
3. Open:
   - Android emulator/device: `a`
   - iOS simulator/device (macOS): `i`

## Current screen

- Header with menu icon and **MATRITRACK** title.
- Two action cards: **Footings** and **Columns**.
